# DEFENSE: Лабораторна робота №1

## 1. Що і навіщо
Гібридна бекенд-система (Telegram Hybrid CMS) для відкладеної публікації контенту. Спроєктовано базову Event-driven архітектуру для розділення прийому HTTP-запитів (API Gateway) та фонової відправки повідомлень (Worker).

## 2. Топ-3 розбіжності / зрізані кути (проти spec)
(Повний слід промптів та рев'ю в ai/lab1-prompts.md)
1. **Порушення меж модулів (Прямий імпорт Worker в API):** Було закладено як технічний борг і успішно виправлено під час аудиту (API повністю ізольовано).
2. **Авторизація:** Відсутність ролей (RBAC) у таблиці Users (залишено як спрощення для V1).
3. **Сховище:** Зберігання медіа як масив URL, замість повноцінної інтеграції з хмарним S3.
