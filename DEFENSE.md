# DEFENSE: Лабораторна робота №1

## 1. Що і навіщо
Гібридна бекенд-система (Telegram Hybrid CMS) для відкладеної публікації контенту. Спроєктовано базову Event-driven архітектуру для розділення прийому HTTP-запитів (API Gateway) та фонової відправки повідомлень (Worker).

## 3. Ключове рішення
**Вибір інструментів статичного аналізу (Biome)**
*Альтернативи:* ESLint + Prettier.
*Чому обрано:* Biome дозволив налаштувати суворий контроль якості та автоматичне виправлення коду перед комітом (через `lint-staged`) за допомогою одного інструменту. 
*(Деталі у `standards/adr/001-tooling-biome.md`, `002-project-structure.md`, `003-git-hooks.md`)*

## 4. Перевірка
Команда: `npm test` -> успішно (smoke-тест API Gateway віддає 200 OK)
Команда: `npx lint-staged` -> успішно (код форматується автоматично)
