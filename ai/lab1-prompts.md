# Аудит використання AI (Лабораторна 1)

## Ітерація 1: Вибір архітектури та інструментів
**Мій промпт (дослівно):** "Запропонуй 3-4 цікаві темы для Node.js проєкту, які ідеально підійдуть під вимоги Лабораторної №1. Який інструмент для перевірки коду обираємо — ESLint+Prettier чи Biome?"
**Відповідь AI:** AI запропонував Платформу аукціонів, CMS та Моніторинг. Для інструментів порадив Biome через швидкість.
**Мої зауваження та рішення:** Я обрала CMS (Telegram Hybrid CMS), оскільки маю досвід роботи з ботами. Погодилася на Biome для єдиного конфігураційного файлу (зафіксовано в ADR).

## Ітерація 2: Генерація специфікації (docs/spec.md)
**Мій промпт (дослівно):** "Згенеруй spec.md за підходом Bottom-Up (від бази даних)."
**Відповідь AI:** AI згенерував структуру з БД, чергою QueueJobs, модулем Scheduler та Worker.
**Мої зауваження та рішення:** AI запропонував занадто ідеальну архітектуру (космольот). Після код-рев'ю викладача я самостійно змінила критерії у `spec.md`, зафіксувавши, що БД, Scheduler та QueueJobs тимчасово замінені на заглушки для MVP V1.

## Ітерація 3: Реакція на Code Review (Аудит меж модулів)
**Мій промпт (дослівно):** "Як провести реальний аудит меж модулів, який вимагає викладач? Запропонуй архітектурну помилку для навмисного впровадження та наступного виправлення."
**Відповідь AI:** AI запропонував впровадити прямий виклик Worker в API Gateway.
**Мої зауваження та рішення:** Я визнала цю ідею хибною після другого код-рев'ю викладача. Інсценувати аудит — погана практика. Я відкинула цю пропозицію і провела справжній аудит наявного коду, виправивши розбіжності між початковою специфікацією та поточним кодом.

## Ітерація 4: Налаштування Git Hooks
**Мій промпт (дослівно):** "Як реалізувати справжній smoke-тест і виправити хук, який не додає виправлені файли в індекс?"
**Відповідь AI:** AI запропонував `lint-staged` для автоматичної індексації та `supertest` для інтеграційного тесту API.
**Мої зауваження та рішення:** Я прийняла це рішення. Інтеграційний тест `/health` успішно імплементовано, хук працює коректно.
