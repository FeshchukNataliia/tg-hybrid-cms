# Definition of Done (DoD)

Кожне завдання (Feature/Bugfix) вважається виконаним ТІЛЬКИ за умови виконання всіх пунктів:

1. **Код:** Логіка реалізована згідно з поточним `spec.md`.
2. **Якість:** Усі git-хуки проходять успішно (`npm run lint` не видає помилок). Код відформатовано через Biome.
3. **Документація:** 
   - `spec.md` оновлено (якщо змінилися моделі даних або API).
   - Архітектурні рішення зафіксовані в `standards/adr/` (якщо застосовно).
4. **Аудит AI:** Усі використані промпти та рев'ю результатів AI задокументовані в директорії `ai/`.
5. **Захист:** Для фінального злиття лабораторної роботи заповнено файл `DEFENSE.md` за стандартом курсу.
