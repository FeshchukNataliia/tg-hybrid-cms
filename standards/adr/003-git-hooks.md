# Набір перевірок у Git Hooks

- **Статус:** Прийнято
- **Дата:** 2026-10-23

## Контекст і Проблема
Потрібно гарантувати, що в репозиторій не потрапляє невідформатований або неробочий код. Минулі спроби використовувати `biome check --write` напряму в хуку не додавали зміни в індекс.

## Розглянуті альтернативи
1. Жорстке блокування (лише перевірка помилок, розробник виправляє сам).
2. Автоматичне виправлення та індексація через `lint-staged`.

## Прийняте Рішення
Обрано **lint-staged** у комбінації з Husky.

## Наслідки
### Плюси
- Форматування відбувається прозоро для розробника і гарантовано потрапляє в коміт.
- Smoke-тест блокує коміти, що ламають базовий функціонал.
### Мінуси
- Додаткова залежність у `package.json`.
