# Вибір інструменту статичного аналізу (Biome)

- **Статус:** Прийнято
- **Дата:** 2026-10-23

## Контекст і Проблема
Необхідно обрати інструмент для форматування та перевірки якості коду (лінтер). Класичний стек (ESLint + Prettier) вимагає кількох конфігурацій та додаткових плагінів для інтеграції, що ускладнює підтримку.

## Розглянуті альтернативи
1. ESLint + Prettier
2. Biome

## Прийняте Рішення
Обрано **Biome** як єдиний інструмент (All-in-one toolchain).

## Наслідки
### Плюси
- Один конфігураційний файл (`biome.json`).
- Висока швидкість роботи (Rust).
### Мінуси
- Екосистема плагінів менша, ніж у ESLint.
