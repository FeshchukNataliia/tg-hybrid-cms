# Формат Специфікації (spec.md)

Кожна специфікація повинна містити такі розділи (максимум 1 сторінка):

1. **Що і Навіщо (Мета):** Бізнес-ціль модуля або компонента.
2. **Архітектура та Межі:** Як модуль взаємодіє з іншими частинами системи.
3. **Модель Даних (ER):** Опис сутностей, їхніх полів та зв'язків.
4. **Критерії Прийняття (Acceptance Criteria):** Чек-лист умов, за яких функціонал вважається робочим.
