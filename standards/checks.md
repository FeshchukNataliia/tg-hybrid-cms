# Обов'язкові перевірки (Pre-Merge Checks)

Перед злиттям Pull Request (PR) автор зобов'язаний перевірити:
- [ ] Відсутність "зрізаних кутів" у коді (або їх фіксація в `DEFENSE.md`).
- [ ] Усі залежності (NPM) виправдані та узгоджені зі `spec.md`.
- [ ] Хуки (pre-commit, pre-push) відпрацьовують без помилок.
- [ ] Слід AI перевірено та описано в `ai/`.
